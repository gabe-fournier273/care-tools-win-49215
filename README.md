## About care tools

care tools is designed for care settings that need a simple web interface to manage everyday records and planning tasks. It brings together core support items such as weight management, care schedules, resident master information, and genogram references so staff can work from a more connected workflow.

This project is aimed at teams that handle resident-facing operations and need a practical way to organize information without jumping between separate documents or ad hoc trackers. Its focus is on keeping essential care-related data easy to access, update, and review in a browser-based environment.
